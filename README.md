# سوق الجملة | Wholesale Market ERP

نظام Flask + PostgreSQL + SQLAlchemy لإدارة سوق الجملة، البوابة، المتحصلين، الوكلاء، العملاء والمركبات والمحاسبة بالقيد المزدوج.

## النسخة الأولى

- تسجيل دخول وصلاحيات أساسية: مدير، محاسب، متحصل، مراجع.
- شجرة حسابات هرمية مع منع القيد على الحسابات الرئيسية.
- محرك قيود مزدوج متزن: مدين = دائن، مع حفظ مصدر القيد وحالته.
- حسابات نظامية للصناديق، العهد، العملاء، الوكلاء، إيراد الدخول، الإيجارات، الرواتب والمصروفات.
- حركة بوابة دخول أو خروج؛ الدخول يولد القيد، والخروج يسجل حركة تشغيلية بلا إيراد وهمي.
- عند الدخول مع وكيل: مدين حساب الوكيل / دائن إيراد دخول.
- عند الدخول بلا وكيل: مدين عهدة المتحصل / دائن إيراد دخول.
- حفظ المركبة والعميل واقتراح الوكلاء من تاريخ المركبة والعميل.
- نماذج قاعدة البيانات للورديات، التسويات، الإيجارات الشهرية والرواتب.
- تقارير أولية للتحصيل وكشف الحساب وميزان المراجعة.
- واجهة عربية RTL متجاوبة وPWA للهاتف والكمبيوتر.

## قاعدة محاسبية

الحسابات الرئيسية للتجميع فقط ولا يُسمح بالترحيل عليها. كل وكيل وموظف وعميل يجب أن يكون له حساب فرعي مستقل. القيود المرحلة لا تُعدل مباشرة؛ المعالجة الصحيحة لاحقًا تكون بقيد عكسي أو تصحيحي مع سجل تدقيق.

## التشغيل

الأوامر:
git clone https://github.com/zydan25/kareem.git
cd kareem
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python scripts/init_database.py
python run.py

المنفذ: 4040.

## PostgreSQL

الإعداد الافتراضي:
postgresql+psycopg://kareem:kareem@127.0.0.1:5432/kareem

يمكن تغيير المضيف والمنفذ داخل DATABASE_URL دون تعديل الكود.

## خارطة التطوير التالية

1. CRUD كامل للوكلاء والعملاء والمركبات وأنواع المركبات.
2. إدارة الموظفين والمستخدمين والصلاحيات التفصيلية.
3. شاشة التسوية وإخلاء عهدة المتحصل والوكيل واعتماد المدير.
4. سند قبض، سند صرف، تحويلات بين الحسابات، وقيد يدوي مع شجرة وبحث.
5. دورة الإيجار الشهرية والسداد.
6. الرواتب الشهرية وحساب مستحقات الموظفين.
7. دفتر الأستاذ، كشف حساب بحركة ورصيد، ميزان مراجعة، وقائمة دخل.
8. تقارير اليوم والفترة والوردية والمتحصل والوكيل مع الطباعة والتصدير.
9. سجل تدقيق للعمليات الحساسة ومنع العبث.
10. تحسين PWA والمزامنة الآمنة عند انقطاع الاتصال بالبوابة.

هذه البداية مبنية على متطلبات سوق الجملة نفسها، مع الاستفادة من خبرة المشاريع السابقة دون نسخ بنية غير مناسبة للمجال.
