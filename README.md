# سوق الجملة | Wholesale Market ERP

نظام إدارة ومحاسبة عربي لسوق الجملة مبني بـ Flask وPostgreSQL وSQLAlchemy، مع PWA وواجهة متجاوبة للكمبيوتر والهاتف.

## ما تم تنفيذه

### البوابة والتحصيل
- تسجيل دخول وخروج المركبات.
- البحث الفوري برقم اللوحة والفاصل.
- حفظ نوع المركبة والعميل والوكلاء المرتبطين.
- اقتراح الوكيل من تاريخ المركبة والعميل.
- عند ربط الحركة بوكيل: مدين حساب الوكيل / دائن إيراد دخول.
- عند عدم اختيار وكيل: مدين عهدة المتحصل / دائن إيراد دخول.
- الحركة الخروجية لا تنشئ إيرادًا وهميًا.
- ربط كل حركة بمتـحصل ووردية وسند.
- شاشة هاتف مركزة وسريعة للمتحصل مع آخر الحركات.

### الحسابات
- شجرة حسابات هرمية.
- الحسابات الرئيسية للتجميع فقط وغير قابلة للقيد.
- الحسابات الفرعية قابلة للقيد.
- حساب مستقل لكل عميل ووكيل وموظف/عهدة ومستحق راتب.
- قيد مزدوج متزن: المدين = الدائن.
- القيود المرحّلة لا تُعدل مباشرة.
- قيد عكسي لتصحيح القيد المرحل.
- سند قبض، سند صرف، سند تحويل.
- قيد يدوي متعدد الأسطر.
- كشف حساب وميزان مراجعة.

### العهد والورديات
- ورديات صباحية ومسائية.
- تقرير كامل لكل وردية.
- إغلاق الوردية يحسب الحركة الفعلية.
- إنشاء طلب إخلاء لعهدة المتحصل عند وجود مبالغ غير مرتبطة بوكيل.
- اعتماد الإخلاء من المدير.
- الترحيل: مدين الصندوق / دائن العهدة.
- الاحتفاظ بسجل طلب واعتماد وتسوية.

### الوكلاء والعملاء والمركبات
- CRUD كامل مع تعطيل آمن بدل الحذف الفيزيائي للبيانات التي قد يكون لها أثر مالي.
- ربط العميل بأكثر من وكيل.
- ربط المركبة بأكثر من وكيل مع آخر وكيل مستخدم.
- أنواع مركبات نظامية ومخصصة قابلة للإدارة من الإعدادات.

### الإيجارات
- عقود إيجار شهرية للوكلاء.
- إثبات استحقاق شهر على حساب الوكيل مقابل إيراد الإيجار.
- متابعة الأشهر غير المسددة.
- تحصيل الإيجار من الصندوق وإثبات السداد محاسبيًا.

### الموظفون والرواتب
- ملف الموظف والوظيفة والهاتف والراتب.
- حساب عهدة وحساب مستحق راتب لكل موظف.
- إنشاء مسير رواتب شهري.
- تعديل الإجمالي والاستقطاعات في المسودة.
- ترحيل المسير محاسبيًا.
- صرف الراتب من الصندوق من حساب المستحق.

### المستخدمون والصلاحيات
- مدير، محاسب، متحصل، مراجع، ومدير نظام.
- صلاحيات مفصلة حسب الوحدة والعملية.
- منح أو سحب صلاحيات على مستوى المستخدم.
- القوائم نفسها تتغير حسب الصلاحية، وليس مجرد منع الوصول بعد الضغط.
- سجل تدقيق للعمليات الحساسة.

### التقارير والطباعة
- تقرير البوابة حسب الفترة.
- فلترة بالمتحصل والوكيل والوردية.
- تقرير المتحصلين لمعرفة من عمل ومن لم يعمل خلال الفترة.
- تقرير الوردية.
- كشف حساب.
- ميزان مراجعة.
- تصدير CSV لتقرير البوابة.
- طباعة مباشرة من التقارير والقيود ومسير الرواتب.

## قاعدة البيانات وFlask-Migrate

الإعداد الافتراضي لـ PostgreSQL:

postgresql+psycopg://kareem:kareem@127.0.0.1:5432/kareem

القاعدة:
kareem

المستخدم:
kareem

كلمة المرور:
kareem

المنفذ الافتراضي لـ PostgreSQL:
5432

لا يستخدم المشروع `db.create_all()` للإعداد الإنتاجي. المسار المعتمد هو Flask-Migrate:

```
flask --app wsgi db upgrade
```

عند إضافة تغيير جديد إلى الموديلات:

```
flask --app wsgi db migrate -m "وصف التغيير"
flask --app wsgi db upgrade
```

المراجعة الأولى موجودة في:
`migrations/versions/0001_initial.py`

### أول تثبيت

```
cd /home/root/projects
git clone https://github.com/zydan25/kareem.git
cd kareem
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

ضع بيانات PostgreSQL داخل `.env` ثم:

```
bash deploy/pm2-start.sh
pm2 status
pm2 logs kareem-market
pm2 save
```

عند الحاجة إلى تهيئة PM2 للعمل بعد إعادة تشغيل Ubuntu، نفذ أمر `pm2 startup` الذي يعرضه PM2 مرة واحدة للمستخدم root ثم:

```
pm2 save
```

### تحديث المشروع

```
cd /home/root/projects/kareem
bash deploy/pm2-update.sh
```

السكربت:
1. يسحب `main`.
2. يثبت الاعتماديات.
3. يشغل `flask db upgrade`.
4. يشغل seed للبيانات النظامية.
5. يعيد تشغيل PM2.
6. يحفظ قائمة التطبيقات.

## Nginx

الملف:
`deploy/kareem.nginx`

فكرة الربط:

`kareem.alattab.site -> 127.0.0.1:4040`

مثال التفعيل:

```
sudo cp deploy/kareem.nginx /etc/nginx/sites-available/kareem.alattab.site
sudo ln -s /etc/nginx/sites-available/kareem.alattab.site /etc/nginx/sites-enabled/kareem.alattab.site
sudo nginx -t
sudo systemctl reload nginx
```

بعد تفعيل DNS وSSL يمكن تركيب شهادة Let's Encrypt للدومين.
